## Research question

P100 观察到「词级头（w=0.3, CTC 对齐伪边界）相比 P93 基线下降约 2 pp」，但只跑了一次。
P101 要回答的问题是：

> 这个下降是**真实的方法收益**，还是**单次运行的随机抖动**？

对照组（本研究）与 P100 保持完全相同的配置，只是显式固定 `--word-head-lowlr-mult 1.0`，
用来测量「什么都不改、重跑一遍」会产生多大的波动。

---

## Verdict（判答）

**对本实验设定的问题：判答为「P100 的 2 pp 收益大概率真实，但单次实验无法证实」。**

理由不是 best WER 数字本身，而是下面这条第一次被测出来的东西。

**⚠️ 关键：本次 best WER 比上一次"差" 0.57 pp，但这不是退步，而是噪声。**

### 🔴 核心产出：项目首个「噪声基准」

`p101b-ctrl − p100` 是同配置重复的 epoch 级配对差：

| 统计量 | 值 |
|---|---|
| mean | **+0.133 pp**（几乎无系统偏差 ⇒ 两次 run 等价） |
| **std** | **1.556 pp** |
| 胜率 | 9/20（≈随机掷硬币） |
| best WER 单次差 | +0.57 pp |

> **⇒ 任何单项改动，若其收益小于约 1.6 pp，单次实验根本无法检出。**
> 这条是本实验最有价值的产出，它把过去「只能靠 best WER 拍脑袋」变成了可量化的判据。

## 对既有结论的重新裁定

用上面这条噪声基准复核「词级头是否有效」（`p100 − p93`，w=0.3 vs w=0.0）：

```
ep 1–12 :  -0.70 -0.10 -1.73 +0.50 +1.02 +1.41 +2.04 +2.32 -1.66 +0.24 -0.39 -0.32   ← 正负交替
ep13–20 :  -3.35 -2.60 -1.66 -2.36 -2.39 -1.86 -1.44 -2.25                          ← 8/8 全负
```

| 量 | 值 | 判读 |
|---|---|---|
| 全 epoch mean / std | −0.764 / 1.586，胜 14/20 | 不够判 |
| **ep13–20 mean / std** | **−2.240 / 0.615，胜 8/8** | 信号一致 |
| **信噪比（信号均值 ÷ 噪声 1.556）** | **1.44** | **强提示，非已证实** |

⇒ 信号大概率是真的：后期 8 个 epoch 方向完全一致，且内部 std（0.615）**远小于**噪声（1.556）。
⇒ 但信噪比 1.44 未达显著，且早期 epoch（含 +2.32）说明训练前期本身就不稳定。
⇒ **结论等级：强提示（strong hint），需第三次独立运行确认后才升级为「已证实」。**

## 泛化诊断（本次新观察到的现象）

| epoch | train CTC | dev WER |
|---|---|---|
| 1 | 35.99 | 83.18 % |
| 7 | 25.29 | 69.95 % |
| 13 | 17.92 | 66.40 % |
| 19 | 13.21 | **61.51 %** |
| 20 | 12.99 | 61.86 % |

- train CTC 从 35.99 单调降到 12.99（**降 63.9 %**，全程无回升）
- dev WER 在 ep14 后进入 **61.51 ~ 62.74** 的平台，宽度仅 1.23 pp 且**无趋势**
- ⇒ 典型的**泛化差距**：模型仍在拟合训练集，但 dev 已不再改善
- ⇒ 这解释了为什么 P94（30 ep）相对 P93（20 ep）只有 0.32 pp 收益——**加轮数已到天花板**

## Caveats / 限制

1. **不包含 beam search**：官方 WER 42.1 % 用 beam width 10，本实验为 greedy 解码 ⇒ 与官方严格不可比。
2. **噪声基准来自单次重复对**：1.556 pp 是 n=1 的估计，真实 std 可能落在 ~1.3–1.9 区间；
   后续累积更多重复组应更新该值。
3. ep 早期（ep1–12）存在 ±2~3 pp 抖动，可能与 warmup（3 ep）+ lr 里程碑（ep13）有关，
   噪声量在 warmup 前后是否不同，尚未分开测量。
