## 2. 为什么这个结果可信：Δtrain_ctc 也是负的

这是判断"真有效"的关键，也是与 P136 的分水岭：

| 实验 | Δtrain_ctc 趋势 | 解读 |
|---|---|---|
| P136（wd ×10） | **+0.64 → +5.91** | 训练损失降不下去 ⇒ **欠拟合**，正则把模型压死 |
| P137（lr ×2） | −0.50 → +3.04 | 先好后崩 ⇒ 步长过大、训练不稳定 |
| **P138（lr ÷2）** | **+0.86 → −1.37** | **训练损失也更低** ⇒ 真的学得更好 |

P138 不是"学慢一点碰巧泛化好"，而是**优化本身更充分**。权重衰减那次是纯粹被压垮，性质完全不同。

## 4. ⚠️ 判据张力（不擅自改判据，如实列出）

按预先写死的判据（SNR = |mean| ÷ 1.556 ≥ 2），P138 只到 **SNR 1.06**，未达"可判"。
但同一组数据用配对 t 检验：

```
t = mean / (std / √n) = 1.647 / (0.397 / √8) ≈ 11.7
```

张力来源：**1.556 是"同配置重复"的 std，而本次配对的 std 只有 0.397（差 4 倍）**。
这与 10-14 记录的"噪声基准可能偏保守"假设一致（当时观察到 P121 vs P124e 的 std 也只有 0.32~0.83）。

**处置**：
- 保留 1.556 作保守分母，**不回溯改写历史结论**；
- 把 paired t 作为补充统计一并列出；
- 20/20 全胜 + t≈11.7 的方向性证据，强于此前的 hflip(2.00) 与 bf16(2.41)，
  但两者后来都"换配置即不复现" ⇒ **在第二次独立验证前，不升级为"可判"**。
