## Research question

补上官方其余超参（55 轮 + MultiStepLR([35,45], γ=0.2) + 官方 collate 补帧 + bf16）后，
在 hflip + word_head 0.3 的当前基线之上，**能否带来超出噪声基准 1.556 pp 的改善**？

---

## Verdict（判答）

**inconclusive —— 官方全套超参未带来可检测的改善。**

- best 差 **−0.88 pp**（55.84 vs P119 56.72），**远小于噪声基准 1.556 pp**；
- 用更稳健的「平台期均值」比较，差 **−0.54 pp**，同样在噪声内；
- **无法做 epoch 级配对**：P123 里程碑在 35/45，P119 在 13/16（20 轮缩放），
  两者的 lr 轨迹不同，同序号 epoch 不具可比性 ⇒ 拿不到 mean±std / 胜率 / 信噪比。

⇒ 本次实验**不能归因**到任何一个单项。但产出了两个可证伪的假设（见下）。

## 泛化诊断

**train CTC 全程单调下降**（13.9 → 5.52，从未回升），dev 却在 ep39 后掉头向上 ⇒ **泛化差距，不是欠拟合**。

两次衰减的红利**严重不对称**：

| 衰减 | lr | dev 反应 |
|---|---|---|
| 第一次 ep35 | 1e-4 → 2e-5 | **−2.68 pp / 4 轮**（58.52 → 55.84）✅ 吃到 |
| 第二次 ep45 | 2e-5 → 4e-6 | **+1.44 pp**（55.84 → 57.28）❌ 反向 |

第二次衰减后 CTC 仍在降（6.30 → 5.52）而 dev 上升 ⇒ **进入了过拟合区**。
P119 也是衰减后触底即平台（ep33–44 极差 0.88 pp < 噪声）。
⇒ 提示：**γ=0.2 衰减两次可能衰减过头**，但本次无法分离「衰减过头」与「补帧有害」。

## 两个可证伪的假设（本次最有价值的产出）

### H1：官方补帧在本设置下可能有害

| 项 | 数值 |
|---|---|
| bf16 的**预期**效应（P121 实测，word_head=0 配置） | **−3.75 pp**（SNR 2.41，判「可判」） |
| P123 相对 P119 的**实测**差（P123 含 bf16，P119 是 fp32） | **−0.88 pp** |
| **缺口** | 约 **2.87 pp** 需归因给「官方补帧 + 55 轮/[35,45] 调度」 |

若 bf16 效应可在 wh0.3 配置下复现，则这 2.87 pp 的缺口必须由另外两个变量解释。

### H2：55 轮长调度不比 20 轮缩放更好

两次衰减的边际收益递减（第一次 −2.68 pp，第二次 +1.44 pp），
且两次实验都在**衰减后 4–6 轮内触底**（P119 ep33、P123 ep39）。
⇒ 训练轮数不是当前瓶颈。

## Caveats / 限制

1. **解码方式**：本实验为 greedy；官方 42.1 % 用 beam width 10 ⇒ 与官方严格不可比。
   历史已判定（P120）：本项目用 beam(10) 会使 WER 从 61.86 % 恶化到 125.58 %，故不采用。
2. **三变量捆绑**：bf16 / 官方补帧 / 55 轮调度同时改，**本实验不可归因**。
3. **ep1–31 的 WER 作废**：用坏的解码截断算的（虚高 16.08 pp，见
   `incident-P123-pad-decode.md`）。ep31 真实值 58.66 %。
4. **续训引入一次扰动**：`word_classifier` 未进存盘 ⇒ ep32 被随机重建，
   CTC 从 10.65 跳到 13.91，约 2–3 轮才冲掉（ep35 已恢复至 11.85）。
5. **收据为重建**：缺失 `nan_steps_skipped` / `minutes` / `short_samples_padded`。
6. **本次未做 epoch 级配对**（调度不同），信噪比无法计算 ⇒ 只能是 inconclusive。

|---|---|
| mean 差 | ≤ **−1.556 pp** |
| 胜率 | ≥ 6/8 |

- 任一不满足 ⇒ **bf16 效应不稳健**，P121 的 −3.75 pp 需重新审视（可能含偶然成分）

### 第二步（视第一步结果）

- 若 P124d 判活 ⇒ 启动 **P125 隔离补帧**：`bf16 + 20 轮 + 补帧开` vs `补帧关`，
  两个 9 h 跑，判据同上（mean ≤ −1.556 且 SNR ≥ 2）
- 若 P124d 判死 ⇒ 精度方向整体降级，转向 P124c（自监督微调，取决于探针判活）

### 不在计划内

- **不再追 55 轮**：两次实验都在衰减后 4–6 轮触底，长调度已证伪（H2）
- **第二次衰减的价值存疑**：若后续实验统一只衰减一次（γ=0.2 单次或 γ=0.5），
  可作为低成本变体附带测试
