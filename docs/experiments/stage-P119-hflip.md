## 三、为什么前 12 轮看不出来

ep12 出现单点最大差异 **−4.54 pp**，恰好在 lr 第一次衰减（ep13）之前。
⇒ 合理解释：**hflip 是正则化手段，抑制过拟合需要训练到一定深度才体现。**

train CTC 对照（ep18）：hflip **13.19** vs CTRL **13.44**（已实测）
⇒ hflip 组的训练损失略低（−0.25），
但 dev 差距在 ep13 后拉到 2.7~3.8 pp

⚠️ **须诚实说明**：训练损失只差 0.25（相对 1.9%），**远小于 dev 差距 3.3 pp**。
⇒ 「训练拟合更好 + dev 更好 = 真的更好」这个推论**证据不足**，
   不能用它排除过拟合解释。
⇒ **能确定的是**：hflip 组的 dev 曲线在 ep13 后持续低于对照组，
   且配对 6/6 全胜、SNR 1.93。**「非过拟合」这一点尚未证明。**

若要排除过拟合，需看更晚的 epoch（30/40）是否反转 —— P94 已显示 20→30 轮收益仅 0.32 pp，
说明延长训练本身无效，但**延长训练 + hflip** 的交互未测。
