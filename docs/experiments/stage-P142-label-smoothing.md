## 2. 实现说明（数学与 β 换算）

标准 LS 的 `KL(y_ls‖p)` 可分解为：

```
KL = (1-β)·(-log p[true])  +  β·[-(1/N)·Σ_c log p_c]
       └─ 对 CTC 即 CTC_loss ─┘   └─ ls_penalty() ─┘
```

第二项只依赖 log_probs ⇒ **与 CTCLoss 完全兼容**，不必改前向后向。

🔑 **β 在 CTC 上被放大约 9 倍**（实测，见 `test_ls_penalty.py`）：
CTC 对所有对齐路径求和 ⇒ per-step 有效 CE 只 ~1.4，而 uniform 的 per-step CE = log(3516) = 8.17
⇒ penalty/CTC ≈ 326/36 ≈ 9
⇒ **β=0.01 才等效于标准 CE 的 `label_smoothing=0.1`**（与 ref16 Sign2GPT 的强度相当）

⚠️ train CTC 数值会**高于**无 LS 的实验（penalty 项计入 loss）⇒ **不可跨实验横比 train_ctc**，
这是预期的，不代表训练坏了。

## 4. 怎么解读这个"三个都更差"

有两种可能，**本实验无法区分**：

| 假设 | 内容 | 判别方法 |
|---|---|---|
| **H-a** | 这三个改动真的都有害 | 需要重复 run 看是否稳定复现 |
| **H-b** | **P123 的 55.84 含"运气"成分**，任何扰动都会打破它 | **换 seed 重跑**（唯一办法） |

⚠️ H-b 的可能性不低：三个完全不同的改动（lr 向下 / lr 向上 / 正则化）都给出
相近幅度的负向结果（+1.27 / +2.03 / +1.39），这种"一致性"更像是
**基线本身偏高**而非三个改动碰巧都有害。

⇒ 这正是此前一直没做的「**换 seed 验证**」要回答的问题：
**55.84 是稳定水平，还是单次 run 的运气？**
