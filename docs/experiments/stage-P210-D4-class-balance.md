# P210 / D4 — 类平衡 CTC 加权（长尾 / focal 近似，判负）

> 日期：2026-11-07｜状态：**负向，不进 paired_eval / 2 seed / test**
> 关联：`OPT-DIRECTIONS-2026-11-07.md` D4、P57（频次 ≤10 的 dev token 占 26.4%）、
> P191（高频漏词）、D0-b（近义变体 gloss 混淆）
> 依据等级：【有】FGXM（Pattern Recognition Letters 191, 2025，高频功能词好 /
> 低频实词差 + 提出 uWER）、PGFLoss（IEEE MLSP 2025）；【间接】本实现是类平衡样本加权，
> 非 FGXM 的视觉-语言一致性 loss、也非 PGFLoss 的 pose-guided focal

## 1. 动机与预注册判据

P191 显示替换错误占 67.5%，D0-b 显示 dev 替换里近义变体 gloss 与真实语义混淆为主；
P57 显示 train 频次 ≤10 的 dev token 占 26.4%。FGXM 指出 CSLR 官方 WER 被高频
功能词掩盖，低频实词才是真实瓶颈，并提出对 gloss 类别等权的 **uWER**。

**判据（启动前写死）**：dev `WER_official` ≤ **33.60**，且 **uWER 与低频桶 WER 均改善**；
否则判负。明确要求「不能只看总 WER」。

## 2. 方法（最小侵入，默认关闭）

- `p78_train_official_tfnet.py` 新增 `--cb-alpha`（默认 0.0），**不加开关时行为与 P184 一致**。
- 频次表走**训练实际路径** `DPM.PreWords(gloss.split("/")) → word2idx`
  （与 `RGBSeqDataset.__init__` 的 ids 构造逐字一致）。
  ⚠️ 初版按原始字符串统计会漏掉 434 类变体词（`最2`/`很1`/`帮助（我）`）
  共 1703 次出现；修正后 **3515/3516 类覆盖，miss=1（仅表头 `Number Gloss`）**。
- `CTCLoss(reduction="none")` 的 per-sample loss 按句内 gloss 稀有度
  `mean(1/√(freq+1))` 加权，权重归一化到均值 1 后取 `1 + 0.5·(w−1)`
  （α=0.5，温和档），**不改变整体 lr 尺度**；零新增参数、推理零开销。
- 配方逐项沿用 P184（160 / 冻结 conv2d / batch 2 / bf16 / lr 2e-5 / 6 轮 /
  MultistepLR[4,5] / seed 42 / 官方补帧），从 `p184-init-tfnet160.pt` 起。
- 冒烟 PASS（`CB_FREQ: non-zero 3515/3516, median 2.0, min 1.0, miss=1`）。
- 评估脚本 `p210_d4_eval.py`：除 `WER_official` 外报 **uWER**（对 dev 出现的 774 个
  gloss 类别等权）与 **按 train 频次 ≤10 分桶的 WER**；`align_ops` 用 Levenshtein 回溯
  给每个 ref token 标注 match/sub/del，单元测试 6/6 PASS。

### 3.1 uWER / 分桶评估（本次最有价值的产出）

| 指标 | P184 基线 | D4 | Δ（正=改善） |
|---|---|---|---|
| `WER_official` | 34.41 | 34.27 | **+0.14** |
| uWER（774 类等权） | **60.41** | 59.85 | +0.56 |
| 低频桶 WER（692 tokens, freq≤10） | **70.66** | 69.51 | +1.15 |
| 高频桶 WER（2150 tokens） | 18.56 | **19.16** | **−0.60（恶化）** |
| 按 token 加权的 sub+del micro WER | 31.25 | 31.42 | **−0.17（恶化）** |

口径对账：`692 + 2150 = 2842 = P197 的 ref_tokens` ⇒ 分桶覆盖完整、口径一致。

⚠️ **诚实解读：uWER / 低频桶的"改善"是类别间重分配，不是净增益**。
低频桶改善 1.15pp 只作用在 692 个 token，高频桶恶化 0.60pp 作用在 2150 个 token；
按 token 加权后 **sub+del micro WER 反而恶化 0.17pp**。
uWER 对 774 个类别等权，而其中低频类占多数，故放大了低频的微小改善、掩盖了高频退化。
⇒ D4 只是把错误从低频搬到高频，**总 WER 的 +0.14pp 完全在 ±0.77pp 噪声地板内**，
且未做配对 bootstrap（未过主判据按规范不进入终评）。这些 Δ **不构成统计结论**。

## 4. 最重要的诊断结论（与判负无关，值得单独保留）

**FGXM 的论断在本项目上得到量化实证**：

| 对比 | 数值 |
|---|---|
| 官方 `WER_official` vs uWER（等权） | 34.41 vs **60.41**，差 **26.0pp** |
| 低频桶 vs 高频桶 WER | **70.66** vs 18.56，**3.81 倍**，差 52.1pp |
| dev 中出现的 gloss 类别 | 774（词表 3515，dev 覆盖有限） |

⇒ 项目一直优化的「总 WER」有 **3/4 的 token 是高频功能词**（2150/2842），
它们错误率仅 18.56%，把低频实词 70.66% 的错误率**系统性稀释**了。
这解释了为什么 P185/P196/P198/P202/P203/P206/D1/D2 一连串实验都落在噪声内：
它们改变的主要是被高频词主导的总量，而**真实瓶颈（低频实词细粒度区分）几乎没被触动**。

⇒ **方法论建议（不改判据，仅记录）**：后续任何实验除 `WER_official` 外应同时报
uWER 与低频桶 WER，否则既会低估问题，也会把「拆东墙补西墙」误判为改善
（本次 D4 正是活例）。若要做统计判定，低频桶需单独做配对 bootstrap（692 token 的
样本量比整句 515 更小，噪声更大，不能直接套 ±0.77pp）。

## 5. 判定

**D4 判负**：dev 34.27 未达 33.60；uWER / 低频桶虽小幅改善但被高频退化抵消，
micro 指标反而略差；所有 Δ 均在噪声内且无显著性检验。不进 paired_eval / 2 seed / test。

与 D1/D2/D3 一样，属于「在冻结主干 + 6 轮 + 4973 条预算下的增量改动」族群，
结果一致地落在噪声内 ⇒ **该预算下的增量路线已系统穷尽**。
