## 2. 逐方向结论

- **D1（解码侧重排）**：统计 bigram(P197/P166) 与预训练 LM 两条路线均告负。
  Qwen 对 gloss 序列困惑度无判别力，λ↑ 单调恶化到 37.23；
  best 33.88 的配对 CI `[−0.035, 1.091]` 跨 0，oracle 利用率仅 5.9%。
  ⇒ 25.44 的 8-best oracle 仍只是候选集合上界，**不可提取**。
- **D2（一致性正则）**：61 个可训练张量全部变化（正则确实施加），
  但 train ctc 与 P184 逐位几乎相同、33.3pp 泛化间隙未缩小。
  附带发现双前向会额外更新 `conv1d` 的 BN running stats ⇒ 严格说非纯单变量。
- **D3（密集帧级监督前置探针）**：**A 成立**（每词仅 1.06 帧被监督，弱监督确凿），
  **B 不成立**（`corr(词数,TFD边界数)=0.29`，lift 1.17）⇒ 最便宜入口证伪，
  不投入约 1 天的 GTM / Sign Spotting 工程。不等于证伪 GTM 本身。
- **D4（类平衡加权）**：uWER/低频桶小幅改善但高频桶恶化，按 token 加权的
  sub+del micro WER 反而 −0.17pp ⇒ **类别间重分配，不是净增益**。

## 3. 最有价值的副产物：评估口径的系统性偏差

D4 的 uWER 评估（`p184-base-uwer.json`）量化了一个此前只有定性猜测的问题：

| 指标 | 值 |
|---|---|
| 官方 `WER_official`（按 token 加权） | 34.41 |
| uWER（774 个 dev gloss 类别等权） | **60.41** |
| 低频桶（692 tokens, train freq≤10） | **70.66** |
| 高频桶（2150 tokens） | **18.56** |

- 官方 WER 与等权 uWER 差 **26.0pp**；低频/高频错误率 **3.81 倍**。
- dev 中 3/4 的 token 是高频功能词（2150/2842），错误率仅 18.56%，
  **把低频实词 70.66% 的错误率系统性稀释**。
- ⇒ 这解释了 P185/P196/P198/P202/P203/P206 及 D1/D2/D4 一连串实验为何都落在噪声内：
  它们优化的是被高频词主导的总量，**真实瓶颈（低频实词细粒度区分）几乎没被触动**。
- ⇒ **方法论建议**：后续实验除 `WER_official` 外应同时报 uWER 与低频桶 WER；
  低频桶若要做统计判定需单独配对 bootstrap（692 token 样本量更小，不能直接套 ±0.77pp）。

这与 P191 的「替换 67.5%、主矛盾是同类手势细粒度区分」互相印证：
**问题不是模型没学到语言，而是低频实词的视觉判别力不足**。
