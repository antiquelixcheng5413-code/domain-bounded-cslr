## 3. 已确立的结论（按确定性排序）

### 🔴 可判（SNR ≥ 2 或效应远超噪声）

| 结论 | 证据 |
|---|---|
| **分辨率 160 优于 224** | P127：判据区间 mean **+13.29** / std 0.709 / 224 胜 **0/3** / **SNR 8.54**。本项目迄今最强信号 |
| **224 更差是过拟合，不是欠训练** | 224 的 train CTC 全程更低（ep15: 13.57 vs 15.10）但 dev 更差 |

### 🟡 判死（方向明确，无收益）

| 结论 | 证据 |
|---|---|
| 自监督预训练（SimCLR） | 25 轮后 ΔCohen's d −0.0079、macroAUC +0.0093，双指标趋零 |

| 裁切位置平移 | P129 全量：官方 center 最优，所有平移更差（+0.35 ~ +3.17） |
| WER 口径不是缺口来源 | 语料级 55.84 vs 逐句等权 55.31，差 0.53 pp |

## 4. 诊断结论

### 误差构成（P133，全量 dev 515）

```
sub（说错）  864  54.4 %
del（说少）  685  43.2 %
ins（说多）   38   2.4 %
生成率       77.2 %      整句全对 1.17 %（6/515）
```

**生成率随句长崩塌**：1–3 → 92.1 % / 4–6 → 80.5 % / 7–9 → 69.3 % / **10+ → 54.7 %**

⇒ 即便消除全部 del，WER 也只降到 ~32 % ⇒ 欠生成只是部分原因，
**sub 54.4 % 才是大头（判别力问题）**。

### blank 负偏置（P134，零训练成本）

| ckpt | bias=0 | 最优 | 改善 |
|---|---|---|---|
| P123 | 55.84 | 0.75 → 54.75 | −1.09 |
| P124e | 59.61 | 1.00 → 58.80 | −0.81 |

两个 checkpoint 曲线同为平滑 U 形、最优区间同为 0.75–1.0 ⇒ **效应真实**，
但幅度 ~1 pp < 噪声 1.556 ⇒ 弱证据。

### 架构升级（P135 评估）

技术上只需 `--module TFNet`（已冒烟跑通）。但官方 VAC→TFNet 只值 3.0 pp，
而我们距官方 VAC 差 10.74 pp ⇒ **换架构会把差距平移**，不解决根本问题。
成本：参数 2.08×、显存 70%、速度 1.7×（20 轮≈15 h / 35 轮≈26 h）。
