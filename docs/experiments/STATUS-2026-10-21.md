## 3. 通道修正（P150）—— 收益 2.11pp，只占缺口 10%

唯一变量是通道，其余逐项核对一致（VAC / 160 / bf16 / official_pad / word_head / lr / vocab / seed 42）。

| | P123（BGR） | **P150（RGB）** |
|---|---|---|
| best WER | 55.84 | **53.73** |
| 峰锐度 | 0.5640 | **0.6242** |
| p_blank | 0.8750 | 0.8747 |

**逐轮配对（仅 ep32+，17 轮）**：均值 Δ **−2.141pp**、std 0.975、**胜率 17/17**、配对 t≈9.05
⇒ SNR 1.38（保守噪声）／2.20（配对 std）⇒ 🟡 **强提示**（方向可信，保守判据下未达"可判"）

🔴 **只占总缺口的 10%**（2.11 / 21.92）⇒ 绝大部分缺口**不是**通道造成的。

## 5. bias 与误差构成（P164）+ 实际样例（P165）

**bias 重扫**：0 / 0.25 / 0.5 / 0.75 / **1.0** / 1.5 → 53.73 / 53.41 / 53.27 / 53.06 / **52.92** / 53.38
⇒ 最优值从 0.75 挪到 **1.0**（0.75 是 BGR 模型上调的）

**误差构成**：sub **52.9%** / del 45.5% / ins 1.6%；生成率 76.4%；整句全对 8/515 = 1.55%
- 🔴 bias 只是把 del 换成 sub（del 695→508，**sub 808→933**）⇒ 没提升识别，只是"多猜"

**逐句 WER 分布**：P0=0% / P25=40% / **P50=50%** / P75=66.7% / P100=140%
（逐句均值 52.55% —— 与语料级 53.73 口径不同，别混用）

**5 条真实样例**（按 WER 分位取，非挑好看的）：

| # | 参考 | 识别 | WER |
|---|---|---|---|
| 465 | 这 事 算了 不行 。 | 这 事 **—** 不行 。 | 20% |
| 291 | 我 买 书 一 。 | 我 买 **—** **妈妈** 。 | 40% |
| 369 | 早 饭 没有 。 | **早上** **吃** 没有 。 | 50% |

⇒ **句式骨架常在（代词、标点），实义词大量替换错误** —— 这正是 sub 52.9% 的直接体现。

## 7. 🔴 对标基准到底该用哪个（2026-10-21 已核实）

官方 README 里有**两套数字**，且都在 CE-CSL 语境下：

| 来源 | 指标 | 值 |
|---|---|---|
| README **Inference 表**（论文模型） | TFNet dev / test | **42.1 / 41.9** |
| README **下载项**（"the latest weight"） | **test** | **32.46** |
| ckpt 内 `bestWerScore`（dev，逐句等权） | dev | 33.19 |
| **我们实测该权重** | **dev，语料级** | **33.92** |

⇒ **同一个官方仓库内部，发布的"latest weight"比论文模型好约 9pp**
（test 32.46 vs 41.9）。这个差不可能来自同一方法、同一数据。

### 我们探了 ckpt，想确认是不是借了 CSL-Daily

| 检查 | 结果 |
|---|---|
| ckpt 顶层字段 | 只有 `moduleNet_state_dict / optimizer_state_dict / bestLoss / bestLossEpoch / bestWerScore / bestWerScoreEpoch / epoch` |
| 训练轨迹 `history` | ❌ **没有** ⇒ 无法用"早期 WER 是否偏低"判断是否有迁移 |
| 分类头形状 | 5 个 classifier 全是 **(1024, 3516)** ⇒ 只有 CE-CSL 的头，**没有 CSL-Daily 的头** |
| 文件名 | `TFNet-CE-CSL-**CSLDaily**-32.46.pth` ← 唯一线索 |
| README 说明 | 只写"the latest weight"，**未解释**为何强于论文 |

⇒ **无法从产物证实**。文件名里的 CSLDaily 是【间接】证据；
但"发布权重比论文好 9pp"这件事本身是【有】确证的（README 两处数字）。

### 三条基准线，报数时必须说明用哪条

| 基准 | 值 | 我们 53.73 差多少 | 说明 |
|---|---|---|---|
| 发布权重（可能含额外数据） | 33.92 dev | **19.81pp** | 我们一直在用，但**可能不公平** |
| 论文 **TFNet** | 42.1 dev | 11.63pp | |
| 论文 **VAC**（与我们同架构） | **45.1 dev** | **8.63pp** | 🟢 **最可比**（架构相同、只用 CE-CSL）|

⇒ **建议**：对外以论文数字（尤其同架构的 VAC 45.1）为主基准，
发布权重的 33.92 作为"上限参考"并注明其来源存疑。
**真实待解释的缺口可能只有 8.6pp，而不是 19.8pp。**

### 🔑 D4 因此变成最关键实验
我们自己在 CE-CSL 上训 TFNet+224+RGB：
- 若得到 **≈42**（贴近论文）⇒ 发布权重的 33.92 一定有论文之外的东西（额外数据/未公开改进）
- 若得到 **≈34**（贴近发布权重）⇒ 配方本身就能解释，那我们的训练还差得远
