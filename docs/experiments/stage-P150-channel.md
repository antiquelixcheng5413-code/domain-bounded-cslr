## 3. 🔴 对 22pp 缺口的意义（最重要的一条）

```
P123 (BGR) 55.84%  ──通道修正──▶  P150 (RGB) 53.73%        官方权重 33.92%
              └── 拿回 2.11 pp ──┘        └── 仍差 19.81 pp ──┘
```

- 通道修正拿回 **2.11 pp**，只占总缺口 **21.92 pp 的 10%**
- ⇒ **绝大部分缺口不是通道造成的**

**这条同时给 D1 的结论划了边界**（重要，防止以后被误用）：
D1 在官方权重上量到的「通道代价 **+63.79pp**」是**推理时换输入**的上界，
本次实测**训练侧**真实收益只有 **2.11 pp**——相差 30 倍。
⇒ 🔴 **任何人都不许再用 D1 的 63.79pp 去推断"修通道能拿回多少"**。

## 4. 为什么只有 2.11pp（与 P160 的自洽解释）

P160 实测：dev 帧**近乎灰度**（通道均值 R165/G170/B174，**\|R−B\| 中位仅 8**）。
⇒ 通道里几乎没信息可丢 ⇒ 修好它自然也拿不回多少。
（若画面纯灰，R=G=B，通道顺序**根本不会有任何影响**。）

同时 P160 也解释了为什么仍有 2.11pp 而不是 0：
预训练 resnet18 的 conv1 有 **20/64 个色拮抗型滤波器**（cos 最低 −0.992），
加上深度网络会把微小差异**逐层放大**（主干特征偏移 42.9%）⇒ 留下一点残余收益。
