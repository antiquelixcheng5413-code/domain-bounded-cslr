# P174 同分辨率软标签 KD — 阶段报告（判死）

> 日期：2026-10-30｜分支：experiment/blank-governance-p0-p38｜状态：负向，判死停训

## 1. 背景与动机
P172 跨分辨率响应级蒸馏已判死（跨分辨率 74≠58 + 跨骨架 3D/2D + KD 占比~3% + 被免费零样本 TFNet@160 35.66% 直接压过）。
A 方向（用户选）：将教师输入分辨率 **224→160**，使教师与学生**同分辨率同帧数**，消除 P172 的两个结构性不匹配；教师 = 发布 TFNet@160 零样本权重（本地已有），其软 posterior 作帧级 KL 目标。机理意图：主诊断"判别力不足 / 峰锐度低（0.624 vs 官方 0.864）" → 软标签比硬 one-hot 多带类间信息，本应缓解判别力不足。

## 2. 方法
- **教师缓存** `p174_teacher_cache.py`：对 train(4973)+dev(515) 全量缓存 TFNet@160 软 logit → `artifacts/cache/p174_teacher/`（5488 npy / 3.5GB）。**关键利好：T_raw == canonical_T（49=49 / 59=59）→ 训练无需 F.interpolate 插值，对齐零误差**（相对 P172 跨分辨率 74≠58 的核心改进）。
- **学生训练** `p174_train_distill.py`：VAC@160（35.25M，**from scratch，无 word_head**），λ_ctc=λ_kd=1.0，T=4.0，lr=1e-4 / wd=1e-4 / batch=2 / MultiStepLR[35,45]@55，BLANK_BIAS=1.0（VAC 同 P150 口径；P172 误用 0.0 系统性差 ~0.8pp）。含 `--resume` 续跑（防重启丢进度）+ ep10 哨兵。

- kd loss 1.38→0.86 **持续下降且 >0** ⇒ KD 确实生效（学生在学教师软分布）；gen率 27.7→63.5 持续升（欠生成缓解，软标签应有之效）。
- 但**绝对 WER 轨迹**：ep04 后 P174 持续比 P150 同期差，差距 0.6→5.2pp **且随 epoch 扩大**。

## 4. 公平性核查（关键）
grep P174 脚本**无 word_head**（无 classifier11 / word_head / 0.300） ⇒ P174 是 from-scratch **无辅助头** VAC@160；而 P150 的 53.73 含 word_head 0.3 正则。对照"被优待"了 P174（无头 vs 有头基线），**即便如此 P174 在 ep16 仍差 5.2pp**；若比 P150 去头基线 55.88，ep16 差 **12.2pp**。

## 5. 结论：负向，判死
- **软标签 KD 不是"无增益"，而是负向**——拖慢 VAC 收敛。差距随 epoch 扩大（0.6→5.2pp）是明确的负向信号。
- 根因推测：T=4 软化把教师判别尖锐度也削平，与"学生需要更 sharp"的主诊断**相悖**；学生学的是更模糊、无助于判别力提升的目标。gen率升但 WER 仍差 = "生成更多但错更多"。
- 验收线：强成功 dev<36.81（教师零样本）完全不可达；P174 终值预计 56–59%，连 P150 的 53.73 都达不到，更别说逼近 33.92。
- 用户 22:xx 决策：**判死停训**（kill PID 466，GPU 释放至 4MiB）。
