# 阶段总结 — 收尾与天花板（VAC@160-RGB = 53.73%）

> 状态：定稿收尾（2026-10-27，用户确认接受天花板，停止加实验）
> 约束：8GB GPU（RTX5060 Laptop）｜CE-CSL（4973 训练 / 515 验证）｜完整 3517 类词表

## 1. 项目最佳与最终判定

- **最佳模型**：VAC@160-RGB（P150），dev WER **53.73%**；+blank bias 1.00 ⇒ 52.92%（弱证据）。
- **与论文/发布权重的可比口径**：
  - 论文 VAC 45.1% ⇒ 我们落后 **8.63pp**
  - 论文 TFNet 42.1% ⇒ 落后 11.63pp
  - 官方发布权重实测 33.92%（自称 32.46%）⇒ 落后 19.81pp（README 自相矛盾，可能借 CSL-Daily，无法证实）
- **结论**：在 8GB 卡 + CE-CSL + 完整词表约束下，**VAC@160-RGB 53.73% 是当前可达天花板**。用户于 2026-10-27 确认接受该天花板，停止加实验。

## 2. 实验账本（全部方向 + 判定）

| 方向 | 实验 | 结果 | 判定 |
|---|---|---|---|
| 通道 R/B | 修复 `--fix-rgb-order` | 训练侧真实收益 **+2.11pp** | ✓ 已采用（P150 基线含此） |
| 分辨率 | D3 VAC@224 vs P150@160 | **160 ≫ 224**（+21pp，RGB 口径） | ✓ 160 更优，224 停用 |
| 词级头 0.3 | P167 消融 | 去掉 +2.15pp（0/24 胜） | ✓ 保留（作正则化器） |
| Gloss LM | P166 n-gram 浅融合 | 单调变差，生成率崩到 2.9% | ✗ 判死（数据稀疏 4974 序列 / 3516 词表） |
| 超参 lr/wd | 主配置搜索 | 1e-4 最优 | ✓ 锁定（调超参须直接在主配置做） |
| 解码 beam/length | 与 greedy 对比 | ≈ greedy | ✗ 无效 |
| 自监督 SimCLR | — | — | ✗ 无收益 |
| 更长训练 | P169 ep50→94（cosine 重置 lr） | best 57.28% 无一低于 53.73，ctc 崩 2.12 | ✗ 负向（过拟合） |
| SWA/EMA | P169 过拟合尾巴 | history 显示窗口 ep70–94 全 57–61%≈59% | ✗ 由 history 判死（无需重跑） |
| dropout 0.3 | P170 单变量对照 P150 | 55.10% vs 53.73%，95.8% 胜率偏向 P150 | ✗ 轻微有害，判死 |
| 更强骨干 CorrNet | 代码核查（未跑） | 框架内 dev **47.2 最差** > VAC 45.1 | ✗ 未做（反证据：换骨干补不了 8.6pp） |

→ **便宜杠杆清单全部排查完毕，无正向解。**

## 3. 8.6pp 缺口的本质

- **主诊断**：判别力不足（峰锐度 0.624 vs 官方 0.864；p_blank 三方≈0.875 相同）⇒ 非解码、非正则、非欠生成。
- 那 8.6pp = 「**我们的** VAC 53.73」 vs 「**论文** VAC 45.1」——是**训练 / 数据层面赤字**（RGB 管线、数据规模仅 4973 样本、训练充分度），**不是骨干容量**问题。换 CorrNet 等重架构无法补此缺口。

## 4. 为什么不再追重架构

- **CorrNet**：同一 TFNet 框架内硬编码的论文 dev WER 排最差（47.2 > VAC 45.1）；3D 时空骨干 + correlation volume = O(T·H²·W²)，8GB 卡需 batch1、单轮约 50–70min、55 轮 ≈ 2–3 天；预期**负向**，性价比极低。`p78` 已内置 `--module CorrNet` 支持（collate 产 5D、原样喂），技术上能跑但结论方向已由框架内排名预判。
- **TFNet 全量**：同理，且官方 42.1 是论文基准（非 CE-CSL），外推无据。
- **光流/帧差 concat 到 VAC**：唯一零架构改动的「运动线索」探针，仍仅 ≈0~+1pp（抛光级），不补 8.6pp；因天花板已接受，未做。
