# P209 / D3 — 密集帧级监督前置探针（零训练，判负）

> 日期：2026-11-07｜状态：**负向，不投入 GTM / Sign Spotting 工程**
> 关联：`OPT-DIRECTIONS-2026-11-07.md` D3、本地 `06_SMART` / `07_TS²-TFD`、
> EMNLP 2026《Beyond CTC Spikes》、P185 / P196（序列级辅助判死）

## 1. 动机与预注册判据

文献指出 CTC 产生**峰值对齐**：每个 gloss 只由少数帧预测，其余帧全分给 blank，
导致弱时序监督、难以学细粒度动态。`06_SMART`（本地）与 EMNLP26《Beyond CTC Spikes》
用密集帧级监督（Sign Spotting / GTM）补 CTC，报告显著收益。

但 P185 多尺度 CTC、P196 WE/WC 都是**序列级/逐帧 max 的弱辅助**，已判负；
D3 的唯一未证伪点是**持续 gloss-to-frame 区间监督**。该工程约 1 天，
故先用零成本 TFD 探针判断「能否拿到可信区间标签」再决定是否投入。

**判据（启动前写死）**：
- **A（弱监督前提）**：非 blank 主导帧占比 < 25% 且每词被监督帧数 < 3；
- **B（TFD 可恢复词区间）**：`corr(真实词数, TFD 边界数) ≥ 0.5`
  且 `|边界数 − 词数|` 均值 ≤ 2.0；
- A 且 B 成立才投入 GTM / Sign Spotting；否则 **D3 判负**。

## 2. 方法（纯 CPU，无训练参数）

- CTC 后验：`artifacts/metrics/blank-gov/p188_logp_p184.pt`（P184 @160，dev 515 条，
  `logp [59, 3516]`）；spike = `argmax≠blank 且 (1−p_blank)>0.5` 的帧。
- TFD 信号：landmark48（每条 `(48, 368)` float32），按本地 `07_TS²-TFD` 定义，
  `TFD[t] = || x[t] − local_mean(x, win=5)[t] ||₂`，边界 = 超 75 百分位阈值的局部极大。
- 时间维对齐：两者用归一化坐标 `[0,1]`，命中容差 `±3/47`。
- 有效样本 **514**（`dev-00403` 无 landmark，与 P206 记录的缺失一致）。
- 成本：约 1 分钟 CPU，**与 GPU 上的 D2 训练并行，不占用算力**。

## 3. 结果

| 指标 | 值 | 判据 | 结论 |
|---|---|---|---|
| **A** 非 blank 主导帧占比 | **0.1290**（12.9%） | < 0.25 | ✅ |
| **A** 每词被监督帧数 | **1.06**（参考均长 5.52 词） | < 3 | ✅ |
| **B** 平均 TFD 边界数 | 5.75（vs 平均词数 5.52） | — | 边际接近 |
| **B** `corr(词数, 边界数)` | **0.2895** | ≥ 0.5 | ❌ |
| **B** `|边界数−词数|` 均值 | 1.24 | ≤ 2.0 | ✅ |
| **C** TFD 边界命中 CTC spike | 0.6298（随机基线 0.5378，lift **1.17**） | 辅助 | 弱相关 |

**判定：A=True、B=False ⇒ STOP，D3 判负。**

## 4. 解读（注意 A 成立、B 不成立的组合含义）

1. **A 成立**坐实了文献诊断：CTC 峰值对齐在本模型上确实极端——
   12.9% 的帧主导非 blank，**每个 gloss 平均只有 1.06 帧被监督**。
   密集帧级监督在**理论上**确有空间，不是伪问题。
2. **B 不成立**说明瓶颈在「拿不到可信的区间标签」：
   `corr = 0.29` 表示 TFD 边界数几乎不随句子真实词数变化——
   平均 5.75 vs 5.52 只是**全局巧合**（固定的 75 百分位阈值必然产出相近数量的峰），
   不是逐句对齐。用它去切 gloss 区间，等于给 CTC 灌噪声标签。
3. **C 的 lift 1.17** 进一步佐证：TFD 边界与 CTC spike 只是弱相关，
   既没提供互补的时间结构，也没精确复现 CTC 已有对齐。

⇒ 若要做 D3，只能走 **GTM 原路线：用 LLM/MLLM 生成 gloss-to-frame 区间监督**
（EMNLP26 的做法），或先提升 landmark 质量（HaMeR 手部网格、面部韵律）。
但这两条都要 ~1 天工程 + 额外模型，且本项目 6 轮预算内未必收敛
（P200 已证随机初始化大模块在 4973 条上 6 轮拟合失败）。
按预注册规则，**不投入**，避免在又一个高成本方向上换噪声内结果。

⚠️ 诚实边界：本探针只证伪了「**无参数 TFD + 现有 landmark48**」这一最便宜入口，
不等于证伪 GTM / Sign Spotting 本身。判据 B 是工程可行性的门槛，不是机制证伪。
