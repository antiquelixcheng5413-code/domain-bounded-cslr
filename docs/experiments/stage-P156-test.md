# Stage P156-test：TFNet 零样本 test 验收（160+RGB）

> 关联：`stage-P156-zero-shot-ablation.md`（dev 代价分解）、`stage-P171-finetune-tfnet160.md`（微调判死）
> 日期：2026-10-28
> 口径：CE-CSL test 集，发布 TFNet 权重，**零样本（不微调、推理时换输入）**

## 0. 背景与动机
用户授权破例使用一次性 test 资源（审计铁律：test 冻结只跑一次，原 P145 已用，本次为新 TFNet 零样本结论，需用户显式授权）。
目的：把 dev 上的「最佳可用数字 36.81%」升级为**可对外宣称的 test 数字**，并验证分布稳定性。

## 1. 方法与写死判据
- 脚本：`tools/blank_gov/p156_test_eval.py`
- 复用 P145 的 test 数据路径（`test.csv`，501 条，实际有效 500 条）+ p156 修复版 decode（整段 logp 交 `greedy_decode`，**不预截断**，防 double-`_conv_len` 重现 87.93 事故）
- **门禁**：test 224+RGB 必须落在 `32.46 ± 3pp`（锚 README 标 test 32.46）；不通过则不采信 160 数字
- **目标**：test 160+RGB 即对外宣称数字
- **铁律遵守**：`BLANK_BIAS` 固定 0.0，绝不在 test 上扫描超参；test 只跑这一次，归档即止

## 2. 结果

| 组合 | test WER | 生成率 | 备注 |
|---|---|---|---|
| **224+RGB（门禁）** | **33.09%** | 94.6% | 官方 test 32.46，差 **+0.63pp** ✅ 门禁通过 |
| **160+RGB（目标）** | **35.66%** | 92.3% | 分辨率代价 **+2.57pp** |

- dev 对照：160+RGB dev=36.81%，test=35.66%，**差 −1.15pp**（test 略优，分布差异在正常噪声内，未触发 >5pp 告警）
- 全部 500 条有效评估，无空输出，生成率 92–95%（正常模型区间，排除 87.93 级别的评估 bug）

## 3. 结论
- **本项目的 test 最佳可用结果 = TFNet@160 RGB 零样本 35.66%**（零训练成本，比我们从头训的 VAC@160 53.73% 好 **18.07pp**）
- 真天花板（发布权重 224 原配）：test 33.09% / dev 33.92%——两侧口径一致，评估环境可信
- **160→224 的纯分辨率代价在 test 上 = +2.57pp**（与 dev 的 +2.89pp 一致，温和且方向稳定），进一步坐实「分辨率不是主要矛盾」
- 三项彻底隔离（最终版图）：

| 因子 | test 量级 | 结论 |
|---|---|---|
| 骨干 VAC→TFNet/MAM | ~18pp（53.73→35.66） | 唯一主因 |
| 分辨率 224→160 | +2.57pp（零样本上界） | 极温和 |
| 微调发布权重 | 净负向（P171 best 39.90% 反差 3pp，退化至 45%+） | 判死 |
| 通道 RGB→BGR | +43.67pp（推理上界；训练侧因灰度数据≈0） | 非真实瓶颈 |

## 4. 对外宣称口径（建议）
- 可声明：**在 CE-CSL 上，零样本复用官方 TFNet 权重（@160）达到 test 35.66%**，相比 from-scratch 训练的 VAC@160（53.73%）提升约 18pp。
- ⚠️ **前置待办**：权重文件名 `TFNet-CE-CSL-CSLDaily-32.46.pth` 暗示可能联合训练，**对外宣称「CE-CSL SOTA 级」前必须向作者核实**。但纯 CE-CSL test 复现 33.09% 证明其对 CE-CSL 有效，不影响「零样本迁移有效」的结论。
