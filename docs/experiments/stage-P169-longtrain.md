# 阶段报告 — P169：warm-start 长训练 + 余弦退火（VAC@160 + RGB）

- 日期：2026-10-25 起
- tag：`p169-longtrain-rgb`
- 配置：VAC / img-size 160 / RGB / word-head 0.3 / `--sched cosine --eta-min 1e-6`
- **warm-start 自 `p150-rgbfix-best.pt`（ep49, 53.73）**，`--no-resume-sched`（lr 重置回 1e-4、用余弦退火覆盖扩展段 51 轮）
- `--swa-start 70`：ep70+ 做 SWA 权重平均，结束 `update_bn` 后终评
- 计划 100 轮（实际新增 ep50–100，约 21h）

## 动机

- 主诊断：判别力瓶颈；易得杠杆（通道/分辨率/LM/词级头/beam/超参/SimCLR）已穷尽。
- 待验假设：「55ep + 官方 MultiStepLR 是否已到该配置最优？」→ 长训练 + 余弦退火是单变量最干净检验。
- 同时顺带 SWA（对平台期模型常给 0.5–1pp 平滑增益，零额外训练成本）。

## 写死验收判据（启动前定，照此办）

- 与 P150 逐轮配对（取双方都有的 epoch 区间）+ best WER 对比。
- **Δ ≥ 2pp 且胜率 ≥ 75%** 才算「有效增益」；否则记为「噪声内，55ep 已近最优」。
- SWA 单独判：与 P150 best、P169 best 三者互比，注明是平滑增益还是过拟合。
- 报数必须 mean±std + 胜率 + SNR（噪声基准 1.556pp）。

## 风险 / 备注

- 预期收益弱（1–2pp）：我们早有结论「lr 最优依赖调度长度、55ep 在该调度下是谷底」。
- 真实价值 = 把「调度长度是否够」从推断坐实为证据，并补 SWA 一项。
- 若 P169 与 P150 无统计差异 ⇒ 反向支持「判别力瓶颈非正则/调度可解」，报告据此收敛结论。
