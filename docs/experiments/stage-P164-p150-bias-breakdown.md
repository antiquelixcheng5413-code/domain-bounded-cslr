⇒ 病根不是"不说"，是"说了但说错"

### 🔴 一个很有意思的机制观察：bias 只是把 del 换成了 sub

| | bias=0 | bias=1.00 |
|---|---|---|
| sub | 808 | **933**（↑） |
| del | 695 | **508**（↓） |
| ins | 24 | 63 |
| WER | 53.73 | **52.92** |

⇒ bias **没有提升识别能力**，只是让模型"多猜一些"：
减少漏词（695→508）的同时**增加替换错误**（808→933），净 WER 略降。
⇒ 又一次印证：**瓶颈在判别力，不在生成量**。
（这与 P148 的 length penalty 结论同源：把输出拉长并不能变准。）
