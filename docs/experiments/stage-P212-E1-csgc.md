## 2. 方法（单变量，其余配方逐项沿用 P184）

- 原型表 `[3516,1024]` 用 **`NormLinear` 列归一化权重**初始化 —— cosine 分类器天然类原型，
  覆盖全部长尾类（含只出现 1 次的 48%）。
- 帧→gloss 用 **CTC 后验软聚合**，不需要帧级标注；正类=真实 gloss，
  负类=后验最高的非目标类（hard negatives），InfoNCE + 动量 0.99 / τ=0.07 / n_neg=16。
- 挂 `classifier11` hook **只取第一次调用**（该对象在 TFNet 里被复用 2 次，第二次是 conv1d 的 x）。
- **训练期-only，推理零开销**；`--csgc-*` 默认关闭，不改任何已有实验行为。
- 配方：160 / 冻结 conv2d / lr 2e-5 / wd 1e-4 / batch 2 / bf16 / seed 42 /
  6 轮 / 从 `p184-init-tfnet160.pt` 起。λ=0.3。

**审计三层校验（排除静默空操作）**：冒烟 PASS（proto `(3516,1024)`）；
梯度自检 PASS（loss 2.96，feat 与 CTC logits 梯度非零、原型保持单位范数）；
CPU 真实前向 `model(vid, dl, True)` 下 hook 捕获 `feat (78,2,1024)`、CSGC loss 1.756 > 0，
时间与 batch 维和 `main_lp` 对齐。

## 6. 诚实解读

- 尾部确实**小幅改善**（uWER −1.15pp、低频桶 −1.58pp），方向与 CSGC 的立论一致，
  但幅度都落在 dev 噪声地板 ±0.77pp 附近的量级，且**高频桶同时恶化 0.56pp** ——
  与 D4 同构的「类别间重分配」，只是幅度更小。不能算净增益。
- train ctc 逐位相同说明对比项**没有改变主任务拟合**，只是把表征几何轻微挪动；
  在「冻结主干 + 6 轮 + 4973 条」的预算里，动量原型来不及为 48% 单样本类形成稳定边界。
- 这不等于证伪 CSGC 本身：原论文在 CSL-Daily 上从零训练更长周期；本项目是
  发布权重上的 6 轮 PEFT，两者训练预算不可比。
- ⚠️ 本判定用的是 E1 链原生判据（未含插入数护栏）。夜间链 S0 会用统一评估器
  `night_eval_full.py` 重新出全指标 + 插入数，并按统一 R1–R7 复判，结果见
  `stage-p212-e1-night.md`。两处判定如有差异，以含护栏的统一口径为准。
