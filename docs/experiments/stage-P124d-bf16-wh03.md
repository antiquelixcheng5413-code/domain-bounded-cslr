## 机理解释（⚠️ 依据【无】，是我的推测，但 P124e 可证伪）

bf16 尾数只有 8 bit ⇒ logits 精度下降。而词级头的**伪边界来自 CTC 贪心路径**：

```
bf16 → logits 精度下降 → CTC 贪心路径更易切错 → 词级头拿到更差的伪标签
     → 用一个错的监督信号去教共享时序特征 → 有害
```

而 word_head=0 时没有这条通路，bf16 只剩"尾数截断 = 隐式正则"的作用 ⇒ 有益。

**这个假设的直接推论**：在 bf16 下**去掉词级头**（P124e = bf16 + wh0）应当
明显好于 P124d。**P124e 正在跑，就是对这个推论的检验。**

## 对 P123 结论的修正

此前在 P123 报告里我推测：「bf16 预期 −3.75 pp，而 P123 只 −0.88 pp
⇒ 缺口 2.87 pp 需归因给官方补帧 + 55 轮调度」。

**这个推算现在作废**，因为它用了错误的 bf16 效应值（−3.75 是 wh0 配置测的，
而 P123 是 wh0.3）。用本次实测的 +1.656 重算：

```
P123 − P119 = −0.88 pp
其中 bf16 贡献 = +1.656 pp（有害）
⇒ 「官方补帧 + 55 轮调度」贡献 ≈ −0.88 − 1.656 = −2.54 pp（有益）
```

⚠️ 仍是粗估（P119 实际跑了 44 轮，P124d 是 20 轮），但**符号翻转了**：
官方补帧 + 长调度可能不是有害的，反而有约 2.5 pp 的收益。

## Caveats / 限制

1. **SNR 1.06 < 2** ⇒ 未达"可判"，只能算强提示。需要第二次独立 run 才能坐实。
2. **胜率 1/8 是最强信号**，但 seed 仍为 42 ⇒ 不是独立复现。
3. **P119 跑了 44 轮**（漏传 `--epochs` 导致），P124d 只有 20 轮 ⇒
   best 差 3.48 pp 里含轮数差异，**不可直接比 best**。本报告只信 ep13–20 配对。
4. 途中崩溃 1 次（sticky error），由队列 `--resume` 续训，损失 <1 轮。
5. 解码为 greedy；官方用 beam 10 ⇒ 与官方严格不可比。
