## 3. Q1 — 判负是否稳健

**配对 bootstrap**（20000 次、seed 42、句子级、三份收据 sid 已逐句同序）：

| 对照 | ΔWER 点估计 | 95% CI | 含 0 |

| base vs seed42 | -0.035 pp | [-0.907, +0.854] | 是 |
| base vs seed43 | -0.106 pp | [-1.092, +0.888] | 是 |
| base vs **两 seed 逐句平均** | -0.070 pp | [-0.929, +0.794] | 是 |

**逐句一致性**（相对 base，n=515）：两 seed 同时改善 45 句（8.74%）、
同时恶化 40 句（7.77%）、分歧 1 句（0.19%）、至少一方持平 429 句（83.30%）。

⇒ 两个独立 seed 的 WER 点估计同为负（-0.035 / -0.106 pp）、配对 CI 均跨 0，
合并后仍跨 0；且两 seed 在低频桶改善（70.66→69.94 / 69.65）的同时
**高频桶同步恶化**（18.56→19.95 / 20.60）、micro 同步恶化（31.25→32.13 / 32.55）。
这是**稳定复现的类别间重分配**，不是 seed 抖动 ⇒ K1 的 FAIL 稳健。
