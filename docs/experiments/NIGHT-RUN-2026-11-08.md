## 3. 两个最有价值的结果

**① F0 差一点过线，但方向被 P218 证伪。**
τ=0.3/β=2.0：低频桶 +2.60pp、uWER +1.67pp、总量 +0.10pp、插入 90→89，
唯一未过的是 R1（差 0.33pp）。顺此假设「只在低置信度非 blank 帧做校正可减少误伤」，
P218 用门控版实测 uWER 只 +1.24pp、低频 +2.02pp，**反而弱于全局版** ⇒ 假设不成立。
S5 也证明训练期改动与解码期补偿无任何互补。

**② P219/P220 第一次给出错误结构的直接证据（新方向依据）。**
严格 Levenshtein 回溯（515/515 句自检 == 官方实现）得到 **693 个替换对**：
- 错误对文本嵌入 cos **0.1974** vs 条件随机（固定 ref、随机 hyp）**−0.001**，
  Δ=+0.1984，配对 bootstrap CI **[0.1747, 0.2214]** 不含 0；
- 甚至**高于正确相邻 gloss 对的 0.0817** ⇒ 模型倾向把词预测成比真实上下文更相似的近义词；
- **字符串变体对 = 0**（`最2/最` 类不是主因）⇒ 高相似不是词表假象；
- 低频 ref 占替换对 **56.28%**；高频对是真近义/词形衍生：
  `？↔。`×43、`学→学习`、`吃饭→吃`、`漂亮→美`、`我→你`、`那→这`。

⇒ 与 P191「替换 67.5%」、D4「低频桶 70.66 vs 高频 18.56」闭环：
**主矛盾 = 近义 gloss 的细粒度判别边界，集中在低频实词**。
