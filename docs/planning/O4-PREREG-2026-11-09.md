## 0. 立论（为什么这是最后一个口子）

- **I0**（改输入帧率：step2/step3/repeat2 全恶化）与 **L1**（改后验邻域：6 档全被护栏拦下）
  共同证明「每词 1.06 个非 blank 帧被监督」是 **CTC 固有属性，推理期任何操作都动不了它**。
- ⇒ 唯一剩余变量是**训练期的监督密度**。
- **K1 的 A 阶段**已用 CTC Viterbi 强制对齐把 train 全量切成
  `p230_k1_clips.json`（28272 片段 / 3515 gloss / 区间中位 28 输入帧 ≈ 8 编码器步），
  J1 在 dev 上独立算出 31.48 帧交叉验证成立 ⇒ GTM 最大障碍「边界从哪来」已解决。
  区间中位 8 步、spike 仅 1 步 ⇒ **约 87.5% 的区间帧未承担标签发射**，是可用新信息。

## 1. 方法（唯一单变量）

**其余逐项沿用 P184**：`p184-init-tfnet160.pt` / 160 输入 / hidden1024 / 冻结 conv2d
（每轮 `conv2d.eval()`）/ lr 2e-5 / wd 1e-4 / batch 2 / bf16 / seed 42 / 6 轮 / ms=[4,5] /
official-pad / fix-rgb-order / dev 515 句评估。**模型结构、CTC 损失、解码、评估管线零改动。**

新增的只有训练期辅助损失：

| 项 | 写死值 |
|---|---|
| 区间来源 | `p230_k1_clips.json`（K1 A 阶段 CTC Viterbi 强制对齐，**静态**，不随训练更新） |
| 区间映射 | **比例映射** `t = round(frac × T_conv_b)`，`frac = a/n_jpg`（用原始目录 jpg 总数归一），彻底避开 `MAX_FRAMES` 下采样导致的帧索引错位 |
| 监督位置 | `classifier11` 的**输入特征** `feat [T,B,1024]`（复用 `FeatureCapture`，只取第一次调用） |
| 目标原型 | `model.classifier11.weight.t()` 按行 L2 归一化后 **detach**（= 当前分类头列向量，**不新增可训练参数**） |
| 损失 | 区间内每帧 `CE( cosine(feat_t, W)/τ , gloss_id )`，对全部区间帧取均值 |
| **λ** | **0.3**（与 E1/G1 同量级便于对照；写死，不扫网格） |
| **τ** | **0.07**（与 E1 一致） |
| 作用范围 | **只加在特征层辅助 loss**，不改 `main_lp`、不动 blank logit、不改类先验、不新增 CTC 头 |

### 与已判死项的区别（必须成立，否则本实验无意义）

| 已判死 | 机制 | O4 差别 |
|---|---|---|
| **P185** 多尺度 CTC（35.50 明确负向） | 不同特征层各加 CTC 头 | 不新增 CTC 头、不改对齐路径集合 |
| **F1** 训练期 logit adjustment（35.47） | 改类先验 logits，破坏 blank 结构 | 完全不动 logits / blank / 先验 |
| **E1 CSGC**（34.41 FAIL） | 动量原型 + 后验软聚合 + InfoNCE 负采样 | 静态 Viterbi 区间 + 固定分类头权重 + 帧级 CE，无动量/负采样 |
| **F2 VTA**（34.27 FAIL） | Qwen 文本嵌入做类原型目标 | 用视觉侧分类头自身权重，不用文本嵌入 |
| **D2 一致性**（34.17 FAIL） | 两视图自洽 KL | 用外部对齐标签，不是自洽约束 |
| **D3 TFD 边界**（corr 0.29 STOP） | 无参数 landmark 边界 | 用模型自身 Viterbi 对齐（K1 已验证可切） |

**反证据（已写入，不回避）**：P185「额外监督破坏对齐」、F1「训练期改 CTC 损失明确负向」、
EMNLP26 自己的消融「**L2 边界平滑负收益**」、用同一 P184 权重切分再训会有边界自我强化偏差、
文献收益在 SLT / 全量微调设定下测得而我们是 6 轮 PEFT。
⇒ **先验上落噪声内概率高**，这是「逻辑闭环上最后一个口子」而非高胜率方向。
