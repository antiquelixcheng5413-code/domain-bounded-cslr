# 数据侧提升方案（2026-11-06，仅方案，不启动实验）

> 背景：模型侧三条线已在本轮关闭——224 容量扩展（P199，负向）、Conformer 整段替换时序主干（P200，负向）、冻结主干上的 Conformer 适配器（P198，噪声内）。当前部署基线：
> - 精度优先：官方权重 @224 零样本（test **32.74**，官方 greedy 口径）
> - 速度优先：P184@160 冻主干（test **33.98**）
> - dev 噪声地板 **±0.77 pp**，任何小于该幅度的「提升」不采信。

---

## 0. 一句话结论

数据侧是当前唯一没有被证伪的变量，但**先验收益有限**：P184 的编辑构成是替换 67.5% / 删除 24.5% / 插入 8.1%，而常见增广主要改善鲁棒性、对「近义手势互相替换」帮助不大。因此本方案要求**先做零训练成本的诊断**，用证据决定是否投入训练，避免再来一轮「6 轮 × 4 h 换来噪声内」。

---

## 1. 已排除项（不要再跑）

| 方向 | 证据 | 结论 |
|---|---|---|
| label smoothing（β=0.01/0.05/0.1/0.2） | P142 / 早期 P89 | β=0.2 明确有害，小 β 噪声内，**关闭** |
| 自监督 / 跨视图一致性预训练 | P124a/P124b，官方 CorrNet 在 CE-CSL 比 VAC 差 2.1pp | **关闭** |
| 伪标签 / Noisy Student | P174/P175：CE-CSL 全有标签，且无外部无标签语料 | **不适用** |
| 更多人工标注 | 无预算、无标注流程 | **不适用** |
| hflip | P119：−3.42pp，已包含在 P184 配方中 | **已开启，无需再测开关** |
| 时序 ±20% | 官方默认，已包含在 P184 配方中 | **已开启** |
| 224 输入 / 更大容量 | P186/P193/P199 | **关闭**（含全参微调） |
| 更强时序主干（Conformer 替换） | P200：40.04 vs 34.34，差 5.70pp | **关闭** |

> 因此「数据侧」在本项目里实际只剩两块：**训练期增广/正则** 和 **已有但未用的辅助模态（landmark48/96）**。

## 2. 阶段 D0：零训练成本诊断（先做，约 0.5 h）

### D0-a 训练集 WER —— 判断是过拟合还是欠拟合

用 `p200/p184` 的最佳权重在 **train split** 上做一次 greedy 评估（不训练、不调参）。

| train WER | 解释 | 下一步优先级 |
|---|---|---|
| < 15% | 强过拟合，增广有明确空间 | 先做 E1 / E2 |
| 15–25% | 中度 | 先做 E1，再看 E3 |
| > 25% | 欠拟合，数据量/容量/优化是瓶颈 | **跳过 E1/E2**，直接评估 E4（辅助模态）或停止 |

判据说明：P184 的 train ctc 已降到 6.77–4.7 量级，但 ctc 与 WER 不同构，必须实测 WER 才能判断泛化间隙。

### D0-b 易混词对清单 —— 决定是否值得做定向增广

从已有的逐句编辑文件（P184 paired 输出）统计 **top-50 替换对**（reference token → hypothesis token），按「同一初始手形/同一语义场」分组。

- 若 top 替换对集中在少数手势族（例如数字、代词、方向类动词）⇒ E5（定向增广/重加权）值得做；
- 若替换对高度分散 ⇒ 定向增广无效，只保留通用增广。

### D0-c 域差异核对 —— 已完成的结论

manifest 统计（`data/manifests/ce-csl.csv`）：

```
signer A–L 在 train / validation / test 三个 split 中均有覆盖
每 signer 约 490–507 train、46–55 dev、42–58 test
```

⇒ **不是 signer-independent 划分，也没有明显域偏移**；「换背景/换人」类增广的先验收益应下调，不作为主线。

### D0 实测结果（2026-11-06 已完成）

工具：`tools/blank_gov/p201_d0_diagnostics.py`，权重 `p184-tfnet-freeze-best.pt`，160 输入，greedy。

| split | n | WER | S / D / I |
|---|---|---|---|
| train | 4973 | **1.03%** | 1796 / 106 / 75 |
| dev | 515 | **34.34%**（与历史值完全一致） | 798 / 193 / 90 |

- **泛化间隙 33.3pp，train WER 1.03% ⇒ 判定为强过拟合（远低于 15% 门槛）**，E1 / E2 增广值得投入。
- dev 的 798 次替换里，top 词对可分为三类：
  1. **标点互换**：`？→。` 25、`。→？` 18（≈5%），属标注符号，增广无法改善；
  2. **近义/变体词条互换**：`没有2→没有` 15、`很1→很` 8、`看1→看` 5、`最2→最` 5、`不行2→不行` 4、`真2→真` 3……（≈8%）。词表核对确认 `最2`（freq 76）与 `最`（freq 11）是**两个独立 gloss 条目**，不是错别字，属真实近义混淆；
  3. **真实语义混淆**：`学→学习`、`吃饭→吃`、`他→那`、`那→这`、`我→你`、`笑→喜欢`、`任务→真` 等，才是增广可能帮助的部分。
- D0-b 结论：**替换对并不集中在「手形相似」的单一词族**，E5（易混词定向增广）优先级下调为「条件触发」，主线按 E1 → E2 → E3 执行。

## 3. 候选实验（按性价比排序）

统一控制变量：**P184 配方**（160×160、TFNet、冻结 conv2d、batch 2、bf16、lr 2e-5、6 轮、官方补帧、hflip + 时序 ±20% 保持开启、seed 42），只改增广/正则项。每一轮都与 P184 做**逐 epoch 配对**。

### E1 强空间增广（优先级 1）

> **状态：已测（P202，2026-11-06）——判负。** best dev **35.54%**（ep5）vs P184 **34.34%**，差 **+1.20pp**（超过噪声地板 ±0.77），距筛选线 33.6 差 1.94pp；6 轮逐轮均落后（+0.71/+1.44/+0.74/+1.69/+0.85/+1.02pp），train ctc 全程约为 P184 的 2 倍。不进入 paired_eval / 2 seed / test。详见 `docs/experiments/stage-P184-tfnet-peft.md` §13。

- **假设**：背景、构图、手部位置变化是泛化间隙的一部分；P184 在 160 输入下 `RandomCrop` 的可裁范围有 96×96，空间多样性充足，加成强增广不会像 224 那样被压缩到 32×32。
- **改动**：`build_transforms` 训练分支追加
  - `RandomResizedCrop(160, scale=(0.7, 1.0), ratio=(0.85, 1.18))`
  - `RandomRotation(±8°)` 或小角度仿射
  - `ColorJitter(0.2, 0.2, 0.2, 0.05)`
  - `RandomErasing(p=0.25, scale=(0.02, 0.10))`
  - 验证/测试分支保持**仅中心裁剪**（不得引入随机性）
- **成本**：6 轮约 3.5–4 h
- **判据**：dev ≤ **33.6**（比 34.34 提升 ≥0.74pp，刚好越过噪声地板）才进入配对复跑；否则判负
- **风险**：hflip + 时序抖动已在不小的增广强度上，叠加后可能欠拟合

### E2 强时序增广（优先级 2）

> **状态：已测（P203，2026-11-07）——判负（与基线无差别）。** best dev **34.55%**（ep5）vs P184 **34.34%**，差 **+0.21pp**，落在噪声地板 ±0.77pp 内；距筛选线 33.6 差 0.95pp。逐轮：+0.74 / +0.84 / +0.28 / +0.78 / **−0.14** / +0.28pp，train ctc 全程高于 P184（约 7.9–9.0 vs 4.7–5.4）。不进入 paired_eval / 2 seed / test。详见 `docs/experiments/stage-P184-tfnet-peft.md` §14。
> **结论：E1 明确负向 + E2 噪声内 ⇒ 数据增广这条线关闭**，剩余未证伪的只有 E4（landmark 辅助监督）。

- **假设**：24.5% 的删除错误与语速/漏帧有关，速度扰动和帧掩码可直接对症。
- **改动**：
  - 速度扰动从 ±20% 扩到 **0.7–1.3×**
  - 随机时序裁剪：保留 70–100% 帧，不足补首/尾帧
  - 时间掩码：2 段、每段 ≤10% 帧（SpecAugment 风格，置零或重复邻帧）
- **成本**：6 轮约 4 h
- **判据**：同 E1（dev ≤ 33.6）
- **风险**：CTC 对帧级连续性敏感，掩码过多会破坏对齐；先用 1 段掩码做小消融

### E3 多视图一致性正则（优先级 3）

- **假设**：不引入新数据，用同一 batch 的两个 dropout 视图做对称 KL（R-Drop 风格），压低过拟合。
- **改动**：前向两次（不同 dropout mask），CTC logits 逐帧 KL，λ=0.3；仅在训练期生效，推理零成本。
- **成本**：6 轮约 4 h（两次前向）
- **判据**：dev ≤ 33.8 且 train–dev 间隙缩小；否则判负
- **风险**：CTC 峰值分布尖锐，KL 容易被 blank 主导，需要按非 blank 帧加权

### E4 关键点辅助监督（优先级 4，改动最大）

> **状态：前置探针已完成（P205，2026-11-07），待决策。**
> - 数据面：`ce-csl-landmark48` 共 5487 条（train+dev，无 test），每条**固定 (48,368)** float32、无 NaN；`landmark96` 目录为空（未落盘）。
> - 单模态探针（独立 LSTM+CTC 头，1.39M 参数，60 轮共 2 分钟）：dev WER 100%→**64.12%**（best 64.47% @ep53）后停滞；同期 train ctc 降到 0.72 ⇒ landmark 携带 gloss 信息但天花板远高于 RGB（34.34%），且自身严重过拟合。
> - **方案修正**：原计划的「独立辅助 CTC 头 + 推理丢弃」不共享任何参数（conv2d 冻结、temporal_model 只吃 RGB 特征），**对 test WER 零作用**。要让 landmark 影响指标，只能做**时序级特征融合**（landmark 编码插值到 conv2d 输出步长后拼接/相加），代价是推理必须保留 landmark 分支（需跑 MediaPipe）。
> - 工具：`tools/blank_gov/p204_landmark_probe.py`（对齐检查）、`p205_landmark_only.py`（单模态探针）
> - **已选方向：时序级融合（P206，2026-11-07 启动）**。实现：`tools/blank_gov/landmark_fusion.py`（`LandmarkBank` 懒加载 + train 200 条统计归一化；`LandmarkFusion` = Linear(368→256)+LN+GELU+Dropout+BiLSTM → proj(256→512)，**proj 零初始化 ⇒ ep0 与 P184 严格等价**），在 `model.conv2d` 上挂 forward hook，把 delta 加进逐帧特征 `[B*temp,512]`；融合模块单独 lr 5e-4，`--lm-fusion` 开关默认关闭。
> - ⚠️ **test landmark 不存在**（landmark48 只有 train+dev，5487 条）：P206 只能在 dev 上判定；若 dev ≤33.6，须先补 extract test landmark 才能跑终评。
> - **结果（P206，2026-11-07 完成）——判负（无差别）**：best dev **34.10%**（ep6）vs P184 **34.34%**，**−0.24pp**，在噪声地板 ±0.77pp 内；逐轮 −0.31/−0.04/−0.04/+0.49/+0.04/**−0.45**pp，best 落在最后一轮（6 轮未收敛）。距筛选线 33.6 差 0.50pp，按硬约束不进入 paired_eval / 2 seed / test。用时 225.1 min。详见 `docs/experiments/stage-P184-tfnet-peft.md` §15。
> - **数据侧总结**：E1 +1.20pp（明确负）、E2 +0.21pp（噪声内）、E4/P206 −0.24pp（噪声内）⇒ 数据侧全部到顶，维持双轨 P184@160（test 33.98）+ 官方 @224（test 32.74）。

- **假设**：现有 `data/processed/ce-csl-landmark48`（22 MB）与 `landmark96` 是**已落盘但未用于 TFNet 主线**的模态；手形/轨迹信息可缓解「相似手势替换」。
- **两种做法**（先做便宜的）：
  1. 辅助 CTC 头：landmark 轻量编码器 + 独立 CTC 头，权重 0.3，仅训练期使用（推理可丢弃）
  2. 特征融合：landmark 编码后与 conv2d 特征逐帧拼接（推理需保留，成本上升）
- **成本**：编码器 + 数据管线改动约 1 天；单次 6 轮约 4 h
- **判据**：dev ≤ 33.5 才考虑并入
- **风险**：landmark 质量/对齐误差未知；若 landmark-only 的历史表现很弱，先做单模态探针再融合

### E5 易混词定向增广（条件触发，优先级 5）

仅在 D0-b 显示替换对高度集中时执行：对 top 词族样本增加裁剪/时序窗口采样，或在 CTC 上对易混 token 做轻度 focal 重加权。不要无证据地全面重加权。

## 4. 判定与统计规范（硬约束）

1. **单次 6 轮只作筛选**：dev 必须比 34.34 好 **≥0.7pp** 才进入复跑；否则直接判负，不做 test。
2. **候选必须逐 epoch 配对**：`paired_eval` 对 P184 vs 候选，报均值差、95% CI、胜率；CI 跨 0 即视为无差别。
3. **复跑 2 个 seed**（42 / 43）：CUDA 非确定性下单次 best 可漂移 0.3–1.7pp，单点结论不可信（P83/P85/P89 已骗过三次）。
4. **test 只跑一次**：dev 通过后固定权重、固定 greedy，不做 test 调参。
5. 所有实验落 `artifacts/*-official-tfnet.json` 收据 + 日志 + 权重，文档写进 `docs/experiments/`。

## 5. 执行顺序与预算

```
D0-a  train WER 诊断（0.2 h，纯推理）
  ├─ train WER > 25% → 跳过 E1/E2，直接 E4 或收尾
  └─ train WER < 25% → 继续
D0-b  易混词对统计（0.2 h，纯统计）
E1    强空间增广 6 轮（≈4 h）── dev ≤33.6 ? ──否──> 判负
E2    强时序增广 6 轮（≈4 h）
E3    多视图一致性 6 轮（≈4 h）
E4    landmark 辅助（实现 1 天 + 4 h/次）
```

- 最小可交付：D0 + E1（约 4.5 h），即可回答「数据增广还有没有空间」。
- 若 E1/E2/E3 全部落在噪声内，结论是**数据侧也已到顶**，项目停在 P184@160（33.98）+ 官方 @224（32.74）双轨，不再追加实验。

## 6. 风险与止损

| 风险 | 应对 |
|---|---|
| 增广与已有 hflip/时序抖动叠加导致欠拟合 | E1 先只加 `RandomResizedCrop + ColorJitter`，分两档强度 |
| 训练集 WER 本来就高（欠拟合） | 直接放弃增广主线，转 E4 或停止 |
| landmark 与 RGB 帧率/对齐不一致 | 先做 100 条样本的对齐探针，再上全量 |
| 任何候选只在 best epoch 好、逐 epoch 配对翻转 | 按规范直接判负（历史已发生三次） |
| 误用 test 做伪标签/调参 | 明令禁止；test 只在最终一次性评估 |
