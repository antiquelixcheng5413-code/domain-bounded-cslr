## 3. 候选方向（按性价比）

### G1. 用真实混淆对做最小对立体 hard negatives —— 优先级 1

- **依据**：【有】Zhang & Duh, EMNLP 2023：手形最小对立体识别率仅 ~20%（运动类 ~87%）；
  【有】Yin et al., arXiv:2606.28667 (2026)：明确建议把最小对立体作 hard negatives，
  并指出姿态流强于手形、像素流强于位置；
  【有】本地 P219/P220 已**直接挖出 693 个真实混淆对** ⇒ 不需要外部最小对立体标注，
  这是本项目第一次拥有「模型实际会混淆哪些词」的监督信号。
- **做法**：在 E1 的 CSGC 原型对比框架里，把负类从「后验最高的非目标类」换成
  **P219 混淆表里该 ref 对应的真实 hyp**（并保留一部分随机负类）；
  或加一个成对 margin loss，强制 `cos(w_ref, feat) > cos(w_confusable, feat) + m`。
  训练期-only，推理零开销。
- **与已判死项的区别**：E1 用「模型自己后验挑的 hard negative」，本项用「dev 上实际发生的、带 ref 的错误对」，
  信号来源不同；D4 是改 loss 样本权重，不改变类间几何。
- **⚠️ 数据泄漏红线**：混淆对来自 **dev**，直接拿 dev 当训练监督会污染 dev 评估。
  ⇒ 必须先在 **train 集**上用同样方法挖混淆对（train 有过拟合风险，需留出或交叉），
  dev 混淆表**只用于先验诊断**，不得进训练。这一条是硬约束。
- **G0-lite 已完成（P221，08:20）**：把 693 个 dev 混淆对放回 train 标注，得
  ref 频次中位 **8** vs hyp 频次中位 **31** ⇒ 替换错误中过半是
  **「低频实词被换成高频近义词」**（ref ≤10 占 56.28%，hyp ≤10 仅 22.94%）；
  混淆对在 train 同句共现率 **16.67%** vs 随机词对 1.20%（13.9×）。
  ⇒ 两个含义：① 长尾先验偏置与 E0/D4 诊断一致，但**纠偏路线已被 E0(post-hoc)、F1(训练期) 两次证伪**，
  所以 G1 应聚焦「判别边界」而非再调先验；② 共现率虽高但 83% 不共现，
  train 混淆表能否覆盖 dev 混淆对仍未验证，**完整 G0（train 前向）仍是 G1 的硬前提**。
- **判据（预注册）**：统一 R1–R7，且额外要求**低频桶单独配对 bootstrap CI 不含 0**（692 token）。

### G2. 分类头判别边界 / margin —— 优先级 2

- **依据**：【间接】ArcFace / CosFace 加性角边距（人脸识别长尾同类）；
  【有】本地 E0：`NormLinear` 列范数被强制相等（`corr(freq,‖w‖)=0.10`），
  类原型缺少区分近义类的结构；【有】P220 证明近义混淆真实存在。
- **做法**：对 P219 混淆对加 cosine margin，或只对「低频 + 高混淆」类做类原型去相关正则
  （`‖W^T W − I‖` 在混淆子图上）。比 F2 的「牵引到文本语义」更直接：F2 是拉向外部先验，
  这里是**推开易混类**。
- **风险**：3516 类里只有 693 对有观测，覆盖稀疏；margin 过大可能伤及高频功能词。

### G3. 低优先 / 不建议

| 方向 | 理由 |
|---|---|
| 词表变体归一化 | P220 变体对 = 0，触发前提不成立；且改 3516 词表破坏可比性 |
| 再做解码重排 / 先验校正 | D1、P197、E0、F0、P218 五连负；S5 证明与训练期改动无互补 |
| 再加全局损失项 / 一致性正则 | D2、P196、P198、E1、F2 全在噪声内 |
| CLIP/SigLIP 骨干、生成式 CSLR、224/Conformer/蒸馏/通用增广 | 本地历史已全部判死 |
| 继续调 F1 的 τ 或 F2 的 λ | 判负后调参 = p-hacking，必须新开实验重新预注册 |

### 一个保留信号：E3 的 1-NN 27.44%

手形/姿态样本级描述子留一 1-NN 预测主 gloss 达 **27.44%**（随机 0.617%，44×），
但 KMeans AMI 仅 0.0599 ⇒ 全局聚类与 gloss 标签不一致，**近邻检索却有效**。
【间接】这提示「检索式 / kNN 增强」可能比「聚类伪标签」更适合本地 landmark。
⚠️ 反证据：test 集没有 landmark（P206 已记），此路只能做诊断或需另补 test 特征，部署价值有限。

## 4. 方法论硬约束（累计教训固化）

1. 所有实验必须同时报 `WER_official + uWER + 低频桶 + 高频桶 + ins/sub/del + micro`；
   仅总量或仅尾部改善都不算正向。
2. **低频桶 692 token 需单独配对 bootstrap**，不能套 ±0.77pp 总量噪声地板。
3. 判据在看到结果前写死，禁止事后调线、判负后调参。
4. dev 只用于筛选；**dev 上挖出的任何统计量不得进训练**（G1 的硬约束）。
5. test 冻结，只在 dev 过线并 2 seed + 配对 bootstrap 复跑后一次性终评。
