## 1. 依据与已知风险（用户约定的等级）

- 【有】arXiv:2606.11925（Robotka et al., 2026）：CTC 强制对齐 → per-gloss 片段 →
  LLM 生成新句 → 随机拼接；Phoenix14T **+2.92 BLEU-4**；
  「真实数据双倍采样」无增益 ⇒ 收益来自合成内容而非多走梯度步。
- 【有】ACM MM 2020 / arXiv:2010.05264：CSLR 任务本身用对齐切段 + 编辑生成伪视频-文本对。
- 【有】arXiv:2401.05336 / EMNLP 2024：CTC 强制对齐分割器人工评估 **93.4%** 准确率。
- 【有】本地 **J1 = CLIP_BANK_FEASIBLE**（`p229-j1j2-probe.json`）：
  spike 仅 1.0 帧/词，但按 spike 中点切出的连续区间中位 **8 编码器步 ≈ 31.5 输入帧**，
  99.26% gloss ≥8 输入帧。
- **⚠️ 必须计入的反证据（文献消融）**
  1. **去掉 LLM 生成、只重组原句反而 −1.34 BLEU-4** ⇒ 必须生成**新 gloss 组合**，
     不能做成同句实例替换。
  2. 合成数据**不可用于预训练**，只能进下游微调 ⇒ 本实验是 PEFT 微调，符合。
  3. **L2 边界平滑负收益** ⇒ 直接拼接，不做过渡优化。
  4. 收益全部在 **SLT（BLEU/ROUGE）** 上测得；我们是 **CTC gloss 识别**（条件独立），
     「新上下文」机制可能打折。**检索确认无 CSLR 上以 tail-class 指标报告该路线的论文**。
  5. 文献承认「同一模型既切分又训练会放大边界偏差」；本实验用 P184 切分 + 继续 P184 PEFT，
     正属此情形，作为已知风险记录。
- 【无】**本实验用本地统计 bigram 生成新句，替代文献的 LLM**：
  CE-CSL 的 gloss 序列不是自然语言、含大量变体词（最2/很1/帮助（我）），
  1.5B 中文模型词表外率高且无法保证序列合法。统计生成可控、零 GPU、可审计。
  这是**启动前写死的工程妥协**，不是看到结果后改方案；其效果未知，如实标注【无】。
- 【间接】统计 bigram 只是「新组合」的载体；若判负，不能区分是「语料合成无效」
  还是「统计生成质量不如 LLM」，这一局限写入报告。

## 2. A 阶段：train 片段库（train only，零训练参数更新）

- 对 train 全量做一次 fp32 前向（复用 `p222` 的 batch1 / MAX_T400 / `synchronize()` /
  每 25 句分片断点 / 自动重试），取 `out[0]` 的 log-prob。
- 对每句用**参考 gloss 序列**做标准 CTC Viterbi 强制对齐（扩展状态
  `[blank, g0, blank, ..., blank]`，转移 stay / +1 / +2），与 J1 同一实现。
- 每个 gloss 的连续区间 = 相邻 spike 中点到下一中点；按该句
  `T_true / T_conv` 换算成**输入帧索引**（`T_true` 取 collate 的 `true_len`）。
- 片段库 = `gloss_id -> [(dir, s, e), ...]`，`dir` 相对 `RGB_ROOT/train`，
  `s/e` 是 `sorted(*.jpg)` 的索引；只存路径与索引，**不存像素**。
- 落盘 `artifacts/cache/p230_k1_clips.json`；报告片段数 / 覆盖 gloss 数 / 区间长度分布。

## 3. B 阶段：新 gloss 句（写死数量与规则）

- 生成器 = **train 标注的 gloss bigram 统计 + 低频优先**（本地替代 LLM，见 §1）。
- **N = 1500 条**（≈ train 4973 的 30%）；长度 **3–10**；
  每条**至少含 1 个低频 gloss**（train 频次 ≤10）；所有 gloss 必须在 3516 词表内。
- 排除与 **train / dev / test 任一 gloss 序列精确重复**（用 `DPM.PreWords` 归一后比较）。
- 随机种子 **42**；生成顺序落盘 `artifacts/cache/p231_k1_sentences.json`。
- 泄漏红线：合成句**只来自 train 统计**，不读 dev/test 的标签内容做生成
  （仅用于「重复排除」的集合比对，不用于生成分布）。

## 4. C 阶段：合成样本落盘

- 按句逐 gloss 从片段库随机取 **1 个实例**（种子 42，同类优先无放回）；
  帧按序拼接，**不做边界平滑**（文献反证据 3）。
- 用 **硬链接** `os.link` 把帧写到
  `artifacts/official_rgb/train/k1syn/SYNTH%06d/000001.jpg...`，
  不复制像素（避免约 10GB 占用）；若硬链接不可用则报错停止，不静默改复制。
- manifest = `{sid: ("k1syn", gloss_str)}`，落盘 `artifacts/cache/p232_k1_manifest.json`。
- 合成样本**只进 train**，dev/test 目录零改动。

## 5. D 阶段：训练与判定

- 给 `p78_train_official_tfnet.py` 加默认关闭的 `--k1-manifest`：
  在 `labels_tr = read_csv_split("train.csv")` 之后、`RGBSeqDataset` 构造之前
  `labels_tr.update(manifest)`。**词表仍由 `Word2Id(CSV_DIR/*.csv)` 构建，不受影响**
  ⇒ 训练日志 `wordSetNum` 必须与原 P184 完全一致（审计自检，不符即 INVALID）。
- 6 轮训练，其余参数逐项沿用 P184；每轮存 best/last ckpt。
- 评估：`night_eval_full.py` 全指标 + `night_judge.py` 统一 **R1–R8**
  （主看 uWER / 低频桶，低频桶单独配对 bootstrap，护栏 R3/R5/R6）。
- **判据（写死）**：R1–R8 **全部通过** ⇒ `PASS`（仅代表值得 2 seed 复跑，**不进 test**）；
  否则 `FAIL` ⇒ 不调比例 / 不换生成器 / 不重跑 / 不进 test。
- 额外审计：合成句与 dev/test 序列零精确重复；train 之外的 split 零改动；
  `wordSetNum` 不变；训练 rc==0 且日志含 `ep006` 行（否则 ABORT 不判定）。
