## 0. 依据（用户要求的等级）

- 【有】arXiv:2606.08056《What's the Point? Spatial Grammar & Index Resolution for SLR》
  正文明确 "Evaluation is case-insensitive and **synonym-aware**"，
  Appendix I「Synonym-Based Evaluation Mapping」原文："To avoid penalising
  semantically correct but lexically variant predictions, synonymous forms within
  each group are treated as equivalent during alignment."（BSL 的 I/me 同手势）。
  该文还定义 `WER_Index` / `WER_Lex` 分层指标。
- 【有】Springer 2026 土耳其手语系统综述：WER "lacks context sensitivity"、
  "can also penalize valid paraphrases"，token-overlap 指标会误罚语义等价的转述。
- 【有】本地 P220：693 个严格替换对中**字符串编号变体对 = 0**，但高频对是真近义
  （学→学习、吃饭→吃、漂亮→美、我→你、那→这），且 `？↔。` 合计 43 次为最高频；
  错误对 gloss 文本 cos 0.1974 vs 条件随机 −0.001（CI 不含 0）。
- 【无】把该等价映射用到 **CE-CSL / 中文 gloss** 上无先例；三条等价规则属工程预注册。

## 1. 性质与红线（最重要）

**探索性评估口径诊断**：不判 PASS/FAIL、不产生任何性能主张、不用于模型/λ 选择、
**不进 test**、不改任何已有判据与收据。结论只能表述为
「若把语义等价 gloss 视为同一标签，WER 会是多少」，**不得**写成「模型提升到 X%」。
CE-CSL 官方口径不承认语义归一，34.34 / 34.41 仍是唯一可比数字。

严禁：事后改规则/剔规则/调阈值、只在 dev 上挑参数、把结果当实验收益、
用等价映射做训练或解码、启动训练、跑 test。

## 2. 数据与自检

- `p188_logp_p184.pt`（p184 模型 dev 515 句后验，34.34 同管线）、`dev.csv` / `train.csv` 标注、
  `p214_vta_target.npy`（Qwen2.5-1.5B gloss 文本 PCA1024 嵌入，3516×1024）+ `p214_vta_mask.npy`。
- 解码 `greedy_fast`；严格对齐 `align_ops`（`p210_d4_eval`，已单元测试复现 Levenshtein）。
- **审计自检（硬门禁）**：不施加任何等价规则时，重算的语料级 WER 必须落在
  **[34.20, 34.60]**，且 sub 对总数必须复现 P219 的 **693**；任一不满足 ⇒ 整个诊断标 `INVALID`。

## 3. 三条等价规则（写死，各自独立报，不组合调参）

| 规则 | 定义 | 依据 |
|---|---|---|
| **E1 标点等价** | ref 与 hyp 均属于标点集 `？。！，、；：…·,.!?;:` 且互不相同 | 【有】P220 `？↔。` 43 次；标点常无对应手势，属标注约定 |
| **E2 字符串包含** | 一方是另一方的真子串且长度不同（学/学习、吃/吃饭） | 【无】无参数规则，写死；P220 已证编号变体对=0，但**语义派生**未查 |
| **E3 嵌入 cos ≥ 0.75** | Qwen gloss 嵌入 L2 归一后 cosine ≥ **0.75**（阈值写死），且 mask 有效 | 【有】同义词组等价思想 + P220 错误对 cos 0.1974；0.75 属工程预注册【无】 |

另报**三规则并集**作为宽松上界，但主结论只看三条独立结果。
`WER_syn(rule) = 100 × Σ(edits − n_equiv_sub(rule)) / Σref_tokens`，
其中 `n_equiv_sub` 只扣减严格回溯得到的 **sub 对**，不动 del / ins（防止把删除也"洗掉"）。

## 4. 输出

1. 每条规则：等价 sub 对数、占 693 的比例、`WER_syn`、相对 34.34 的差；
2. **词类分层**（写死）：标点桶 / 低频桶（train freq ≤10）/ 高频桶（>10）的
   token 数、sub 数、del 数、等价 sub 数、对总 WER 的贡献占比；
3. `？↔。` 这一对单独报次数与占比；
4. 等价对的样例（前 12），以及"若按官方口径这些仍算错误"的明确声明。

## 5. 结论表述规则

- 若等价 sub 占比高 ⇒ 结论是「34% 中有相当部分属**评估目标歧义**，不可约，
  进一步支持接受天花板收尾」，**不是**「找到新优化方法」。
- 若占比低 ⇒ 结论是「近义 gloss 判别是真实模型缺陷」，与 P220 一致。
- 无论哪种，都**不产生新的可执行训练方向**；若用户想进一步，需先讨论
  「是否接受改变官方评测口径」这一前提。
