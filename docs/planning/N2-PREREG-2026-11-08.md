## 2. L1 — spike 邻域后验融合扫描（新方向，零训练，纯 CPU）

### 2.1 立论与诚实预期
- D3／I0 证明「每词仅 1.06 个非 blank 帧被监督」，且 I0 证明**重复输入帧只拉长同一个 spike、
  不产生新 spike**。尚未验证的是：spike **邻域帧的后验**里是否含有可用于判别的信息
  （若含，时序平滑/证据聚合能在不改输入、不重训的前提下改善细粒度区分）。
- 与已判死项的区别：P188 是**跨模型 logit 集成**、I0 是**改输入时间分辨率**、
  P187 是**输入变换 TTA**；L1 是**同一后验的时序邻域聚合**，机制不同。
- ⚠️ **反证据优先写明**：I0 已表明邻域帧大概率只是同一 spike 的复制 ⇒ L1 大概率 FAIL。
  证据等级：【无】推理期后验时序平滑在 CSLR 无先例，属工程假设；
  【间接】RAIDAL BMVC26 峰值窗口 / D3 弱监督；【有】本地 I0 的反证据。

### 2.2 方法与固定参数（启动前写死）
- 数据：`artifacts/metrics/blank-gov/p188_logp_p184.pt`（p184 模型 dev 515 句后验），
  与 H1/H2-a 的 **34.34** 同管线同句序。
- 变换（prob 域）：`p'[t] = (1−λ)·p[t] + λ·mean_{j=−k..k} p[t+j]`（边界 replicate padding），
  `logp' = log(p' + 1e−12)`，再 `greedy_fast` 解码。**blank 通道同样参与平滑**（不特例处理）。
- 网格写死：`k ∈ {1, 2, 4}` × `λ ∈ {0.3, 0.6}` = **6 档**，加 `λ=0` 基线共 7 组。
  **不增设 0.8×/1.25× 之类的中间档**（防 p-hacking）。
- 全指标口径逐行照 `p226_h1_knn.py` 的 `metrics()`：WER_official（原始 gloss 串）、
  uWER（类等权）、低/高频桶（train freq ≤10）、ins/sub/del、micro sub+del、
  per_item（含 `sid` / `low_n` / `low_err`）。
- 配对 bootstrap：`night_judge.paired_bootstrap`（20000 次、seed 42、sid 逐句同序断言）。

### 2.3 选择规则与判据（写死）
- **护栏**（对每档）：R3 高频桶恶化 ≤1.00pp；R5 插入增幅 ≤10%；R6 micro sub+del 恶化 ≤0.30pp。
- **chosen** = 护栏内 `WER_official` 最低的档；若无任何档满足护栏，则 chosen 强制为 λ=0 并直接判 FAIL。
- **主判据**：`Δ = WER(λ=0) − WER(chosen) ≥ 2.00pp` **且** 配对 bootstrap 95% CI 下界 > 0
  ⇒ `SIGNAL`；否则 `FAIL`。
- SIGNAL 只代表「值得后续设计训练期时序证据聚合的新预注册」，**不进 test、不自动启动训练**。
- 审计硬门禁：λ=0 基线 WER 必须落在 **[34.20, 34.60]**（已知 34.34），越界整个 L1 标 `INVALID`。
- 产物：`p234-n2-probe.json`、`p234-n2-verdict.txt`、7 组 `-uwer.json`、
  `stage-P234-N2-spike-fusion.md`（含全网格表与机制分析）。
