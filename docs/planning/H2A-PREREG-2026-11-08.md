## 0. 这个实验回答什么问题

H2（参数自适应 TTA）的收益前提是「测试时存在可修复的分布偏移」。
CE-CSL 的 dev / test 来自同一采集协议（同分布），因此方案在 §2 H2 里写死了硬前提：

> 在 dev 上人为加 corruption，测 WER 掉多少；**若掉 < 2pp，H2 直接 STOP**，不投实验。

H2-a 就是这个前提诊断本身。**它不是性能实验**，不产生任何候选模型，不改任何权重。
结论只有两种：`PRECONDITION_PASS`（才允许考虑 H2-b）或 `STOP`（H2 整条线关闭）。

## 1. 依据等级（用户约定）

- 【有】SAME（Yang et al., ACL 2026）：自称首个 SLT 中的 TTA，动机是「现有无监督域适应
  需要 batch statistics 或长时间适应，实时部署做不到」。
- 【有】TRANSLATE（Wang & Wang, IEEE TMM 2026, DOI 10.1109/TMM.2026.3730967）：
  SLT 中**腐败诱导分布偏移**的 TTA，参数无关时序方差解耦。
  其实验设定本身就是在 corruption 下测退化，本诊断沿用该动机。
- 【有】TENT（ICLR 2021）熵最小化通用范式。
- 【有】本地 P187 的输入变换式 TTA（hflip / 多尺度 / 分辨率）已判死 —— 但机制是
  「多视图投票」，与「参数自适应」不同，不构成对 H2 的反证。
- 【有】`OPT-DIRECTIONS-4` 的系统性检索结论：CSLR gloss 层面的 TTA、冻结主干下的 TTA 均未见。
- 【无】**用「轻度档」而非所有档作主判据、以及 4 类 corruption 的具体强度，是工程判断**，
  无直接论文依据，明确标注。理由见 §3。

## 3. corruption 定义（9 组，全部确定性、无随机）

作用在单帧 `im`（uint8）上，`H,W = im.shape[:2]`：

| 组名 | 档 | 定义 |
|---|---|---|
| `clean` | — | 恒等变换（基线） |
| `blur_mild` | mild | `cv2.GaussianBlur(im, (3,3), 0.8)` |
| `blur_med` | medium | `cv2.GaussianBlur(im, (5,5), 1.8)` |
| `jpeg_mild` | mild | `cv2.imencode('.jpg', im, [IMWRITE_JPEG_QUALITY, 60])` → `imdecode` |
| `jpeg_med` | medium | 同上，quality=25 |
| `bright_mild` | mild | `clip(im.astype(float32) * 0.85, 0, 255)`（室内光照变暗） |
| `bright_med` | medium | 同上，因子 0.60 |
| `occlud_mild` | mild | 中心方块置 0，边长 `int(sqrt(0.08) * min(H,W))` |
| `occlud_med` | medium | 同上，面积占比 0.20 |

**为什么主判据只看 mild 档（写死在看到结果前）**：TTA 面向的是真实部署里
同一采集协议内的**轻度自然偏移**（轻微失焦、编码质量、光照波动、局部遮挡），
不是抵御极端破坏。强 corruption 必然让任何模型掉点，那个退化不构成
「存在可被 TTA 修复的偏移」的证据；若连 mild 档都不掉点，说明模型对自然偏移
已经鲁棒，TTA 没有可修复的空间。
**medium 档全部测量、全部如实报告，但不参与判定**（防止用极端破坏刷过线）。

## 4. 每组报出的指标（统一口径，与 `night_eval_full.py` 逐行一致）

`WER_official`、`uWER_pct`（dev 出现过的 gloss 类别等权）、
`low_bucket`（train 频次 ≤10）/ `high_bucket`、`ins/sub/del`、
`micro_subdel_pct`、`ins_rate_pct`、`nonblank_frame_ratio_pct`、
`per_item`（含 `sid / ref_n / edits / ins / sub / del / low_n / low_err`）。

另加方案要求的 **collapse 监控**（供 H2-b 设计用，不参与 H2-a 判定）：
`empty_output_rate`（输出 0 个 gloss 的句子占比）、`distinct_gloss_count`（不同 gloss 数）。

## 5. 判据（唯一，写死）

```
Δ_mild_max = max over {blur_mild, jpeg_mild, bright_mild, occlud_mild}
             [ WER_official(corrupt) - WER_official(clean) ]

若 Δ_mild_max >= 2.00 pp  ⇒  PRECONDITION_PASS（H2-b 才值得设计）
若 Δ_mild_max <  2.00 pp  ⇒  STOP（H2 整条线关闭，不投 GPU）
```

- 判据只用 **mild 档的 WER_official 跌幅**，不看 uWER / 低频桶 / medium 档。
- 其余指标全部报告，用于解释结论，但**不得用来改判**。
- **审计自检（硬门禁）**：`clean` 组 `WER_official` 必须落在 **[34.20, 34.60]**
  （已知 `p184-base-uwer.json` = 34.41，来自同一重新前向口径）。
  越界 ⇒ 判定 `INVALID`，不得给出 PASS/STOP，先查管线。

## 6. 明确禁止

- 不事后调整 2.00pp 阈值、不换 corruption 强度、不挑组、不增设新 corruption 再判；
- STOP 后**不启动 H2-b**，不因为「medium 档掉得多」而复活 H2；
- 不跑 test、不用 dev 标签做任何参数更新（本实验全程无梯度）；
- 不把 corruption 下的 WER 当作模型性能改进或退化结论对外引用 —— 它只是前提探针。
